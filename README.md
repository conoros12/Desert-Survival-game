# Desert Survival Game

A browser-based real-time survival game developed using JavaScript, Python and Flask.

The game allows players to move around a desert environment, interact with enemies and compete for a position on the leaderboard.

## Features

- Real-time player movement
- Combat system
- Player health
- Enemy AI
- Collision detection
- Tile boundaries
- Animations
- Real-time game loop
- Leaderboard
- Database-backed scores

## Technologies

- JavaScript
- HTML
- CSS
- Python
- Flask
- SQLite
- Canvas
- HTTP

## How It Works

The game runs in the browser using JavaScript and HTML Canvas.

The game continuously updates the player, enemies and environment through a real-time game loop.

Collision detection is used to manage interactions between the player, enemies and the environment.

A Flask backend and SQLite database are used to store leaderboard information.

## Game Loop

The game runs at approximately 30 FPS and continuously handles:

- Player movement
- Enemy movement
- Collision detection
- Combat
- Health updates
- Animations
- Rendering

## Backend

Flask provides the backend functionality for the game.

SQLite is used to store leaderboard information, with the browser communicating with the backend using HTTP requests.
